# 券商专家网络采购监控的覆盖范围

目标：允许一天发现延迟，优先提高全国券商相关采购项目的覆盖和召回。不能把任务运行成功或零新增解释为全国没有相关采购。

## 名录与来源

`data/bid-alerts/brokers.json` 保存证监会《证券公司名录（2026年9月）》的完整150条记录，包括单列证券资管机构。这不是150个独立券商集团。来源链接、下载日期、SHA-256和官方序号保存在文件中。

每家机构按检索简称及经核实的历史/品牌别名，分别检索专家、访谈、投研咨询、研究咨询、智库、顾问服务六组主题。原有站点与全网搜索仍保留；工作流中的精简关键词不会再覆盖掉必要的专家网络、专家库等检索词。

目前7家机构配置22个去重后的官方采购入口。逐一的来源依据、访问观测和动态页面限制见 `data/bid-alerts/source-evidence.json`。其余机构可参与逐家搜索，但官方采购入口尚待核实。配置了入口不等于每轮抓取都成功。

已配置的公开来源包括中信、广发、中银、中邮、银河、财通、国投资管的官方/集团采购页面。银河列表为官方公开JSON接口；记录使用真实ID去重，链接指向官方采购列表，详情正文入口尚未核实，不伪造详情URL。

## 减少漏报的处理

- 支持无引号HTML链接，跟随页面实际提供的“下一页”链接；超过本轮翻页限制的页面进入下轮队列。
- 在相关性筛选之前读取采购候选的正文、公开PDF和DOCX。公告明确链接的公开跨域附件和CDN可以读取，最多10个附件、每份10MB。
- 扫描PDF、旧DOC、受限页面、无法解析的附件明确标为待核验。已匹配券商且处于采购语境的项目在读取失败时保留为候选。
- 正文预算外和失败项目保存完整条目，下一轮即使搜索不再返回也会继续读取。正文连续三轮未完整读取时保留到人工核验清单，不认定为无关项目。
- 同网址的实质正文/标题变化可再次提醒。旧版仅URL的历史记录静默建立指纹基线；已有摘要转为首次完整正文则作为更新处理。
- 邮件单封上限仍为50条，超过时分批发送。发送前持久化完整待投递队列，每成功一批才更新对应已发送状态；后续批次失败不会丢失未发送项目。

## 报告与运行

每轮 `work/bid-alerts/coverage-report.json` 记录逐家搜索计划/成功数、各源站结果、读取警告、续读队列、人工核验清单和限制。邮件附带该报告；不完整轮次不会只显示“没有新目标”。报告中的搜索成功数不能当作真实公告召回率。

离线生成任务计划，不联网、不发送邮件、不修改已发送状态：

```bash
python3 -m src.bid_alerts --coverage-plan --report-file output/bid-alert-coverage/coverage-plan.json
```

只读完整扫描会联网，并将报告和续读数据写入指定报告文件；不会发信或修改已发送状态：

```bash
python3 -m src.bid_alerts --dry-run --verbose --report-file output/bid-alert-coverage/dry-run-report.json
```

GitHub工作流配置每日上海时间09:17扫描、17:47备份。默认搜索并发4、单源每轮最多5页、每轮最多读取500份正文、整体网络扫描预算3600秒。优先检查官方源站，最多使用四分之一预算；搜索优先逐家券商，并为最后的正文检查预留四分之一预算。超出部分和失败任务在报告中可查并续读。工作流90分钟上限为收尾和保存报告留出时间。工作流只在推送该版本后采用这些设置。

GitHub Actions的Artifact保留离线计划和运行覆盖报告30天。发送状态、投递队列及续读数据沿用 `work/bid-alerts` 缓存；即使扫描/发送步骤失败，工作流也尝试保存状态。运行失败或定时任务未启动仍需结合Actions状态检查，缓存不是独立数据库备份。

名录更新（可选更新工具依赖为 `xlrd>=2.0.2,<3`，运行扫描不依赖xlrd）：

```bash
python3 scripts/update_broker_registry.py --help
```

## 尚未证明的能力

公开搜索RSS的返回数量和收录范围由搜索服务决定；提高客户端上限不能使它成为完整公告索引。尚未对所有机构完成直连来源适配，也没有完成历史公告全集的召回率回测。仅登录后可见或定向邀请的采购需要对应授权渠道。验收应继续跟踪逐家入口覆盖、已知项目漏报、来源失败及发布时间到发现时间的延迟。

GitHub定时事件仍可能延迟、漏跑，公开仓库长期无活动还可能被自动停用。程序内报告只能反映已启动的任务，不能检测一个完全没有启动的任务；要独立保障连续运行，仍需外部运行心跳或稳定调度服务。

- `pyproject.toml`：增加PDF文本解析依赖。
- `tests/test_bid_coverage.py`、`tests/test_bid_documents.py`：隔离网络和邮件的回归验证。
- `README.md`、`docs/bid-alert-coverage.md`：使用方式、范围及尚未覆盖部分。
